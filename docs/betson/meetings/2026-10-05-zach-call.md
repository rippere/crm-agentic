## Import behavior that needs fixing before his next CSV

Zach plans to import another CSV and asked whether it would replace existing contacts. Ben said it
would only add. That's **only partly true** (`apps/api/app/routers/contacts.py` `import_contacts_csv`):

- Rows whose email already exists get **updated in place, including `status`**. If the new CSV has no
  status column, or says `lead`, every prospect/customer he manually re-statused **gets reset to
  `lead`**.
- Rows without an email are always inserted, so re-importing the same list **duplicates** them.
- Phone, address, city, state and similar columns are **silently dropped**.
